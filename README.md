# 🍀 言葉のクローバー

ヒントの言葉から4枚のカードを当てる連想ゲーム（ボードゲーム「So Clover!」風）のスマホ向けWebアプリです。
インストールすればオフラインでも遊べます（PWA）。

## 遊び方

- **みんなで**：スマホ1台を順番に回して遊ぶ協力モード（2〜6人）
- **ひとりで**：CPUと遊ぶソロモード
  - CPUのヒントを当てる／CPUに当てさせる／交互にやる
  - CPUは内蔵の連想辞書（1801語＋同音異義語・多義語 約1000語義）で考えます
  - 同音異義語のヒント（例：しょうゆ＋金色 →「はっこう」）にも対応
- **カード管理**：1枚4語の固定カード（450枚）。使用済みカードを出さない設定、使用済みの確認・戻す、苦手なカードの除外ができます

データ（使用済みカード・CPUの学習・途中のゲーム）は端末のブラウザ内にだけ保存されます。

## GitHub Pages で公開する

1. このフォルダの中身（`index.html` `manifest.webmanifest` `sw.js` `icons/`）をリポジトリのルートに置いてプッシュ
2. GitHub のリポジトリ → **Settings → Pages**
3. **Source: Deploy from a branch**、Branch: `main` / `/(root)` を選んで Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

スマホでそのURLを開き、
- Android（Chrome）：タイトル画面の「📲 アプリとしてインストール」またはメニューの「ホーム画面に追加」
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」

## 更新するとき

ファイルを差し替えてプッシュするだけです。`sw.js` のキャッシュ名が版ごとに変わるので、
アプリを開くと「新しいバージョンがあります」と表示され、「更新する」で最新版に切り替わります。

## ファイル構成

```
index.html             ゲーム本体（辞書・CPUを含む1ファイル）
manifest.webmanifest   PWAの設定
sw.js                  オフライン用キャッシュ（Service Worker）
icons/                 アプリアイコン
```
